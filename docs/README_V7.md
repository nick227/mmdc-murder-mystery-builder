# v7 Overlay

Focus:
- lock down solution leaks
- improve unique informational value
- strengthen deduction discipline
- rebalance character usefulness

Apply on top of v6/v6.1.

## Main changes
- stronger no-leak prompts across acts, host speeches, clues, items, activities, final editor
- orthogonal clue design requirements
- character secrets and profiles now require balanced suspicion + unique held information
- card quality pass explicitly removes solution leaks and redundancy
- final editor reinforces "imply, do not conclude"

## Goal
Players should infer the truth from cards, not read the answer on the cards.
